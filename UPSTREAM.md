# Upstream

This repository is a fork of [Webstudio](https://github.com/webstudio-is/webstudio)
(AGPL-3.0), imported at commit `8e4c080d95d134f87784cbb6286b3c4acc152235` (2026-09-30).

Goal: a Webflow-like visual builder with our own CMS that has no field-count limits,
running on free-tier hosting (Cloudflare-first) until the platform is proven.
